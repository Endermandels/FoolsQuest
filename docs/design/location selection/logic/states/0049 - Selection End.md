# Description
This state shall:
- Choose a random stat type.
- Call the get_animal method from the Animal Group associated with that stat type.
- Create a [Battle Setup Resource](../../../battle/logic/0050%20-%20Setup%20Resource.md).
- Store the Battle Setup Resource with all elements filled using scene tree meta data.
- Transition to Battle scene.
