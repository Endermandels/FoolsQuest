# Description
This state shall:
- Set units' ATK, DEF and SPD stats back to base values.
- Clear units' temporary passives.
- Report who won.
- If the player won:
  - Transition to [Loot](0053%20-%20Loot.md)
- If the player lost:
  - Transition to Defeat Scene.
