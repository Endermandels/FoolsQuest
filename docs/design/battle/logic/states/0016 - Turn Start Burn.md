# Description
This state shall:
- If the current unit is burning, it takes X DMG. Reduce current unit's burn count, and if it reaches 0, remove burn.
- If the current unit dies, transition to Battle End.
- If the current unit is stunned, transition to Turn End Bleed and remove stun.
- Otherwise, Transition to Action Input.
