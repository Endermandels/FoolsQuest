# Description
Units shall have the following boolean variables indicating status effects:
- is_poisoned
- is_burning
- is_bleeding
- is_stunned
- is_blind

Units shall have the following integer variables indicating status effect terminations:
- burn_turns_left
- bleed_turns_left
- blind_turns_left
