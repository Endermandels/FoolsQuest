# Description
Units shall have the following integer variables indicating stats:
- HP (Health points)
- MP (Mana points)
- ATK (Attack)
- DEF (Defense)
- SPD (Speed)

Units shall have base versions of the above stats.
Stats shall start at their base value.
HP and MP can never go above their base value, nor below 0.
ATK, DEF and SPD can never go below 0, but can go above their base value.
ATK, DEF and SPD should be set to base value at the end of a battle.
