# Description
The dragon starts off defensive, either a Mischievous or Cautious AI, with plenty of HP, MP and DEF, low SPD, average ATK
In this phase, the dragon uses more specials and has defensive passives
Halfway through, the dragon gains an aggressive or feral AI and trades DEF for SPD and ATK
In this phase, the dragon uses less specials and has aggressive passives
