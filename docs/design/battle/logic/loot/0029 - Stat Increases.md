# Description
Loot shall have the same variables named in [0010](../units/0010%20-%20Stats.md).
However, each variable now indicates the stat increase tier (0, 1, 2, 3).
Each tier increases the corresponding stat as follows:
0. No change
1. +1
2. Random low range
3. Random high range
